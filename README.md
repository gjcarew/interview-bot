# Interview Bot 
## Purpose
Software engineering interviews often involve a technical challenge, or coding round. These are done with an interviewer and require the interviewee to understand a problem, plan a solution, implement the solution, and discuss the advantages and disadvantages of the solution they chose. This repo will create an agent-led command line process for practicing technical interviews. 

A secondary purpose of this repo is to gain a better insight into agentic coding workflows, subagents/agent personas, and agent skills with the goal of being writing enterprise-level software taking full advantage of AI tools.
